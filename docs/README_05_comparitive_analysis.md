# Jobs Data Analysis Project

## Project Overview
This project analyzes job-related data using R programming. It explores salary patterns across different job characteristics.

## Dataset
- File name: `jobs_clean.csv`
- Number of rows: 15,000
- Number of columns: 20
- Backup file: `jobs_clean_backup.csv`

## Tools Used
- R Programming
- Base R functions
- CSV files
- PNG graphs

## Analysis Performed
The project includes exactly 8 comparisons:

1. Experience Level vs Salary
2. Employment Type vs Salary
3. Company Size vs Salary
4. Remote Work Type vs Salary
5. Industry vs Salary
6. Job Title vs Salary
7. Education Required vs Salary
8. Experience Level vs Employment Type

## Project Folder Structure

- `jobs_clean.csv` – Original dataset
- `jobs_clean_backup.csv` – Backup dataset
- `Project_Analysis.R` – R analysis script
- `README.md` – Project documentation
- `Analysis_Results/` – 8 CSV analysis files
- `Graphs/` – 8 PNG graphs

## How to Run the Project

1. Install R on your computer.
2. Open `Project_Analysis.R` in RGui or RStudio.
3. Run the script.
4. The analysis CSV files and graphs will be generated in their respective folders.

## Project Output
- 8 analysis CSV files
- 8 graphs in PNG format

## Conclusion
This project helps understand how salary varies according to experience level, employment type, company size, remote work type, industry, job title and education requirements. It also examines the relationship between experience level and employment type.
